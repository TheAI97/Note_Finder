ADMIN WORKSPACE

Keep the library fresh.

Add or replace PDFs, then publish changes for every student on this same website.

How publishing works: Unlock the admin workspace with your admin password. Configure your GitHub repository and token once on this admin device, then use Publish changes. PDFs and a notes manifest are uploaded to the repository, so students keep using the same website link. This password is a browser-side lock only; it is not server-side authentication.
ACCOUNT SECURITY

Change admin password

Choose a unique password of at least 8 characters. It is saved in this browser only, so it will not automatically carry over to another device or browser.

Create a fine-grained token for this repository only, with Contents: Read and write. The token is saved in this browser's local storage, not written into the public HTML. Anyone using this same browser profile may still access it; use a dedicated admin device and revoke the token if exposed.

Save PDF notes first, then click Publish changes. The same live website link will show the updated library after refresh.
Manage uploaded notes
Deleting a note removes it from the next published manifest. Old PDF files may remain in the repository until manually deleted.
